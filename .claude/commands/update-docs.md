# Update Docs

Review the repository and update documentation when installer scripts or commands have changed.

Steps:

1. Inspect `README.md`, `mac/README.md`, and `windows/README.md`.
2. Compare the docs against the behavior in `mac/`, `windows/`, and `windows/src/`.
3. Update install, uninstall, debug, troubleshooting, and verification commands as needed.
4. Keep documentation beginner-friendly and course-focused.
5. Do not change installer behavior unless explicitly asked.
